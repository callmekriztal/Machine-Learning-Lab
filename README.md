# Machine Learning Lab (PCCSL508)

Machine Learning Lab experiments for KTU CSE **Semester 5**

## Course Information

* **Course Code:** PCCSL508
* **Course:** Machine Learning Lab
* **Semester:** 5
* **Credits:** 2
* **Prerequisites:** None

## Course Objective

To gain practical experience with fundamental machine learning techniques by implementing and evaluating algorithms using Python and standard machine learning libraries.

## Experiments

1. Linear Regression
2. Polynomial Regression
3. Ridge and Lasso Regression
4. Logistic Regression (MLE & MAP)
5. Multinomial Parameter Estimation (MLE & MAP)
6. Logistic Regression on Pima Indians Diabetes Dataset
7. Naïve Bayes for Text Classification
8. K-Nearest Neighbors (KNN)
9. Decision Tree (ID3)
10. Logistic Regression vs Decision Tree
11. Linear Support Vector Machine (SVM)
12. SVM with Linear, Polynomial, and RBF Kernels
13. Multilayer Perceptron (MLP)
14. Neural Networks with Different Activation Functions
15. Neural Network Hyperparameter Tuning
16. Hierarchical vs K-Means Clustering
17. K-Means Clustering on Digits Dataset
18. Bootstrapping and Cross-Validation
19. Bagging and Boosting
20. Bias-Variance Tradeoff
